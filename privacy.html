🔐 Privacy Policy & Terms

Your memories belong only to you.

📖 About Memory Diary

  • Memory Diary is a private digital journaling application.
  • It is designed to help users safely store memories, thoughts, emotions, and personal experiences.
  • The application focuses on privacy, simplicity, emotional writing, and secure personal storage.

🔒 Data Privacy

  • Your diary entries are stored only inside your browser using local storage technology.
  • Memory Diary does NOT read, collect, monitor, or upload your personal diary content.
  • No memories, passwords, notes, or private data are sold or shared with third parties.
  • Your memories remain fully under your control.

🛡 Account Security

  • Locked memories are protected using your personal secret PIN.
  • Users are responsible for protecting their own passwords and devices.
  • Memory Diary currently does not support cloud recovery or forgotten password recovery systems.

⚠ Important Storage Notice

  • Clearing browser data may permanently delete stored memories.
  • Reinstalling the browser or resetting the device can remove diary data.
  • Users should maintain their own backups if necessary.

🚀 Future Updates

  • Future updates may improve design, security, features, and user experience.
  • Memory Diary may later include optional cloud backup and synchronization systems.
  • Open-source versions may be released publicly for educational purposes.

✅ Terms Of Use

  • Users agree to use the application responsibly and legally.
  • Malicious copying, impersonation, harmful redistribution, or abuse of the project is prohibited.
  • Memory Diary is provided "as-is" without guaranteed permanent storage protection.
